# Bridge v1.2 Production Critical Path

## Execution limits

- One Worker task owns one function, one schema change, or one homogeneous test group.
- Implementation and full-suite verification are separate tasks.
- Worker implementation tasks target 10 minutes and have a 15-minute hard limit.
- After two failed edit or tool attempts, the Worker writes `CHECKPOINT.md` and `ASSISTANCE_REQUEST.md` instead of continuing.
- A timed-out task is never rerun as the same large prompt. The Architect salvages the diff and creates only the smallest missing follow-up.
- The Architect owns integration, cross-platform reruns, live remote checks, and release decisions.

## Critical path

| Step | Owner | Scope | Entry condition | Acceptance |
|---|---|---|---|---|
| P1 | Architect | Salvage and validate W01 remote bootstrap | W01A stopped | Parser, focused bootstrap checks, no local paths in remote prompt |
| P2 | Architect | Salvage and validate W02 policy runtime | W02A stopped | Focused runtime suite passes on Windows and Linux |
| P3 | W03 | Windows inherited-pipe proof only | None | Measured parent exit and full 25/25 suite |
| P4 | Worker short task | Remote result commit capture only | P1 passes | Sensitive-file refusal and Bridge-owned commit tests |
| P5 | Worker short task | Result bundle digest/import only | P4 passes | Digest mismatch, corrupt bundle, and ancestry tests |
| P6 | Worker short task | Generic finalizer lifecycle only | P2 passes | Once-only cleanup behavior tests |
| P7 | Worker short task | CloudSite profile only | P6 passes | Plan-only deploy/rollback and safe cleanup evidence |
| P8 | Architect | Main workspace integration | P1-P7 pass | Clean registry, exact three GLM-5.2 Workers, parser and diff checks |
| P9 | Architect | Two-server live Git round trip | P8 passes | Both remote CLIs edit isolated branches without Git credentials |
| P10 | Architect | Release gate | P9 passes | All suites and production acceptance pass; local v1.2 baseline commit |

No production deployment, push, service installation, or CloudSite mutation is part of these steps.
