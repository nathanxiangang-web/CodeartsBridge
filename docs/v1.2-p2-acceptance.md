## Fixes Applied

### TEST 2: DrainIncomplete gate (architect)
- **Root cause:** Linux doubly-forked background process `(sleep 30) &` does not inherit collector pipe handles. DrainIncomplete=False is correct platform behavior, not a regression.
- **Fix:** On Linux, assert process exits normally instead of asserting DrainIncomplete=True.

### TEST 4: UTF8 encoding (w01)
- **Root cause:** Windows OEM codepage cannot encode surrogate pairs (emoji), producing 20000 bytes instead of 40000.
- **Fix:** Set `[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)` in child script.

### TEST 10: Windows path-separator (w01)
- New test verifying backslash and drive-letter path containment on Windows.

### TEST 11: Linux path containment (architect)
- New test verifying POSIX absolute path, backslash literal filename, and symlink escape rejection on Linux.
- **Bug found:** `Join-Path $root 'back\slash.txt'` normalizes backslash to forward slash on Linux.
- **Fix:** Use `$root + [System.IO.Path]::DirectorySeparatorChar + 'back\slash.txt'` direct concatenation.

### bridge.ps1 bug fixes (architect)
- `Invoke-SshShellWorker` line 1332: remoteProjectPath used local GetFullPath resolution. Changed to `$Project.projectRoot` directly.
- `Invoke-SshShellWorker` line 1322: ssh-shell worker used remote cliPath for local Test-Path. Changed to `Find-CodeArtsCli`.

### workers.json transport fix
- worker-02-remote and worker-03-remote transport changed from `ssh` to `ssh-shell`.
