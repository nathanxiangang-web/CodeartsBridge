## 3. Worker assignment (parallel tracks, disjoint files)

| Worker | Transport | ProjectId | Track | Files owned |
|---|---|---|---|---|
| worker01-local | local | codex-glm-bridge | Windows validate + harden | `tests/Test-PolicyRuntime.ps1` (Windows branch only) |
| worker-02-remote | ssh-shell | codex-glm-ma-w02 | Linux validate + path tests | `tests/Test-PolicyRuntime.ps1` (Linux additions) |

Disjoint-file rule: worker01 edits only Windows-skipped/skip-condition lines;
worker02 adds only Linux-path test blocks; worker03 writes no source, only the
acceptance report. No merge conflict possible.

## 4. Execution sequence

1. Architect syncs current project source to both remote Linux roots via scp
   (scripts/ + tests/ + protocol/WORKER.md).
2. Architect creates three task directories with META.json + inbox/TASK.md.
3. `bridge.ps1 dispatch -MaxWorkers 3` (three different projectIds, allowed).
4. Each worker runs `tests/Test-PolicyRuntime.ps1` on its platform, fixes only
   its owned files, writes RESULT.md + TESTS.md + DIFF.stat to outbox.
5. Architect collects three outboxes, runs final cross-check, writes P2
   acceptance sign-off.
